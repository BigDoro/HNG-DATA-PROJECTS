HNG Internship: Data Analysis Portfolio

Overview
This repository contains a collection of data science and analytics projects completed during the HNG Internship. 
These projects span various domains—including retail, entertainment, transportation, politics, and digital marketing—demonstrating my proficiency in the full data lifecycle: from collection and cleaning to advanced modeling and visualization.

Core Technical Stack
Languages: Python (Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn), SQL (PostgreSQL/MySQL).
Tools: Microsoft Excel (Advanced Pivot Tables & Power Query), Power BI, Google Keyword Planner.
Techniques: Machine Learning (Anomaly Detection), Geospatial Analysis, Feature Engineering, SEO Analytics, and Business Intelligence.

Project Directory
Stage 0: Superstore Sales Performance Analysis
Objective: Descriptive analysis of a 10,000-row retail dataset.

Key Achievement: Identified the "Technology" category as the primary revenue driver ($2.26M total sales) and optimized inventory insights using Excel Pivot Tables.

Stage 1: Movie Recommendation System EDA
Objective: Data preparation and feature engineering for the MovieLens 100K dataset.

Key Achievement: Engineered features to mitigate User Leniency Bias and Popularity Bias, establishing a robust foundation for predictive modeling.

Stage 2A: HNG Ride SQL Business Analysis
Objective: Operational audit of a ride-sharing platform using SQL.

Key Achievement: Quantified Year-over-Year (YoY) growth and developed complex SQL queries to identify top-tier drivers based on rating and completion benchmarks.

Stage 2B: Lagos Election Outlier Detection
Objective: Two-layered anomaly detection using Machine Learning and Geospatial analysis.

Key Achievement: Implemented Isolation Forest and Ball Tree algorithms to flag statistically significant voting irregularities in 11,000+ polling units.

Stage 3B: SEO & Keyword Analytics
Objective: Competitive analysis of the Nigerian Banking digital landscape.

Key Achievement: Created a Power BI dashboard correlating SEO keyword difficulty with business-critical functions like "Loans" and "Account Opening."
